臨時異動人員

移植電腦版「一鍵變更排班」的連鎖最少調整流程：新增人員先接替移除人員原班；技能不符時，依技能名單順位搜尋最少職務槽位的連鎖調整。找不到完整路徑時整組不修改。

請先匯入包含當日班表、人員技能順位及輪休／休假名單的 Windows 快照。

新增／移除人員配對

每一組新增與移除人員必須成對。移除者限當日已排班人員；新增者限當日輪休或休假人員。最多三組，與電腦版 AL3:AL5、AO3:AO5 輸入區一致。

電腦版規則對照

  • 先嘗試新增人員直接接替移除人員原班。
  • 不符合技能時，以最短連鎖路徑搜尋可接替人員。
  • 技能順位作為同長度候選路徑的排序依據。
  • 新增人員加入班表；移除人員轉入輪休；新增人員從輪休／休假名單移除。
  • 沒有完整可行方案時，不寫入任何異動。

Email 信箱設定

只在手機設定收件信箱。寄送時由 iPhone 分享面板開啟 Mail，ZIP 附件會自動夾帶；iOS 不允許網頁預填 Mail 收件人，請在 Mail 草稿中確認／貼上此地址。APP 不會讀取或保存信箱密碼。

電腦 → 手機

可選 QR Code 掃描，或使用 Mail 郵件附件交換。以下兩種方式都能把 Windows 班表匯入手機。

✉️ Mail 郵件匯入（Windows → 手機）

① 在 iPhone Mail 開啟 Windows 寄來的 ZIP 附件。② 點分享／儲存到「檔案」。③ 回到這裡按下方「選擇郵件 ZIP 附件」，選取剛才存好的 ZIP。④ 按「匯入 Windows 班表」。
